\section{Discussion}
\label{sec:discussion}
\textbf{What the box label rewards.} Three independent lines of evidence point the same way. The same predictions lose 0.55 AUPRC when scored against the pixels that actually changed (Sec.~\ref{sec:res-h1}); the box model is indifferent to blurring the box interior but not its rim; and a box detector trained on the same labels reaches %YOLO_DISC_NUM
. A benchmark that scores localization against the edited field's box therefore measures \emph{field detection}. That is a useful capability for triage, and box detection delivers it cheaply, but it should not be reported as pixel-level tamper localization.

\textbf{The marker is a shortcut, not the whole story.} Pasting only the residual green line onto an authentic image is enough for the standard box model to find the field, and its test AP drops from 0.97 on images that carry the residue to 0.69 on images that do not. Yet a box model retrained on marker-repaired images keeps 0.916 validation AUPRC (0.923 before) and gains slightly on residue-free Gemini images (0.756 vs.\ 0.722). The residue is used when present and replaced by other cues when removed, which means the headline AIForge-Doc numbers overstate the difficulty-adjusted performance on marker-bearing images, but do not consist of the marker alone. Since the marker is 86\,\% Gemini and 2\,\% Ideogram, held-out-generator results on v1 confound generator and marker; repairing the marker is a prerequisite for any generator-transfer claim on this dataset.

\textbf{Recommendations for document-forgery benchmarks.} (i) Release the authentic source with every training forgery, as AIForge-Doc does, and report a pixel-change metric next to the box metric. (ii) Remove generation-pipeline annotations (markers, crop borders) from the released images and audit residue with a simple colour test. (iii) Report box-level AP separately from pixel metrics, with a box detector as a baseline. (iv) Report leakage-free test subsets and group-aware confidence intervals.

\textbf{Limitations.} The pixel-change ground truth is derived automatically ($\varepsilon{=}8$ with morphology); its agreement with a vision-language check is high (69 OK, 26 partial, 1 wrong of 96 pairs), but no human annotation was performed. The second architecture, the marker-repaired and joint-loss models, the 20-epoch runs and the YOLO ablations use one seed; only the main U-Net grid, the held-out-generator U-Nets and the main YOLO model use three. Ideogram contributes 126 held-out images. TruFor could not be fine-tuned because its training code is not released, so learned in-domain models are compared with zero-shot references only. Image-level detection is measured on validation pairs because the test authentic set is not paired. We evaluate one dataset; AIForge-Doc~v2~\cite{wu2026aiforgedocv2} uses the same box annotation and is the natural next test.

\section{Conclusion}
\label{sec:conclusion}
On AI-inpainted financial documents, the official box masks train and reward detectors of the edited field, not localizers of the changed pixels: changing only the training mask reverses the model ranking, the effect replicates across decoders, and a tiled box detector %YOLO_CONC_NUM
. A residual edit marker in most Gemini forgeries is exploited when present; retraining without it preserves most of the box score but removes the marker-specific advantage. Pixel-change supervision gives the most faithful masks and the fewest false alarms, but neither it nor joint supervision closes the generator gap. We recommend reporting pixel-change and box metrics side by side, auditing generation residue, and treating held-out-generator results on marker-bearing data with caution.
